# 🏆 Sistema de Gestão para Maratona de Programação (Linguagem C)

> 📌 **Contexto do Projeto:**  
> Projeto acadêmico desenvolvido durante a disciplina de Algoritmos e Programação, com o objetivo de consolidar fundamentos essenciais da linguagem C, manipulação de memória e estruturas de dados heterogêneas (`structs`).

---

## 🎯 Objetivo de Aprendizado
O objetivo deste repositório é registrar minha evolução técnica e prática com C puro, exercitando:
* Modularização de código em funções.
* Manipulação manual de vetores e cadeias de caracteres (`char[]`).
* Algoritmos de ordenação implementados do zero (Bubble Sort com critérios de desempate).
* Validação de fluxos de entrada e tratamento de regras de negócio via terminal.
